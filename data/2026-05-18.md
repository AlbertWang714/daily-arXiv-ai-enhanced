Method: OP-Mix uses cheap simulations via low-rank adapters to find optimal data mixtures, avoiding the need for proxy models and aligning with the model's learning dynamics.

Abstract: Data mixing decides how to combine different sources or types of data and is a consequential problem throughout language model training.
